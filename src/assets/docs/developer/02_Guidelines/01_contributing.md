# Contributing Guide

Thank you for your interest in the Input-Output project!

## Code Style
- Use TypeScript strict mode.
- Follow the existing Atomic Design structure.
- All Engine logic must be validated by `scripts/iogl-tool.ts`.

## Submit a PR
1. Create a feature branch (`feature/your-feature`).
2. Ensure all unit tests pass.
3. Submit a PR with a brief description of the changes.

# Quick Start

Welcome to Input-Output. This guide will help you build your first computational graph quickly.

## 1. Place Your First Node
Right-click on the canvas or use the top menu to place an `Input: Number` node.

## 2. Connect Nodes
Place a `Math: Addition` node and connect these two nodes together.

## 3. View Results
Connect to an `Output: Terminal` node to see the calculation results in real-time.
